# 🚀 Multi-Brand Professional Portfolio (Next.js & Tailwind CSS)

## 🌟 Project Overview

This project serves two primary purposes:
1.  **Professional Portfolio:** To showcase specialized technical expertise across five distinct "brand" landing pages (one main gateway, four specialized sub-brands).
2.  **Learning and AI Assessment:** To provide a robust, modern environment for learning **React** and **Next.js App Router** architecture while simultaneously testing the capability of **Generative AI (Gemini)** to act as a development assistant and accelerator.

The entire site is built as a high-performance, statically exported web application.

---

## ✨ Unique Architecture & Core Features

This project utilizes a unique approach to host multiple, independent landing pages within a single codebase, maintaining consistency and separation simultaneously.

### 1. Multi-Brand Landing Pages
The project is structured to host five independent landing pages:
* **Main Gateway:** `/` (Features the Brand Selector Grid).
* **Four Specialized Brands:** (`/tech`, `/photo`, `/spotting`, `/tyto`, etc.), each featuring unique assets, branding, and content, but sharing the same core components.

### 2. Static HTML Export
The project is configured for **Static HTML Export (`output: 'export'`)**, which means the entire site is pre-rendered into HTML, CSS, and JavaScript files at build time.
* **Benefit:** Enables deployment on any simple static hosting service (Netlify, GitHub Pages, Nginx) with maximum performance and minimal hosting cost.
* **Router Fix:** Uses `trailingSlash: true` in `next.config.js` to ensure clean URL routing (e.g., `/tech/` resolves to `out/tech/index.html`) without needing server-side routing logic.

### 3. Key Technical Components
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS (utility-first approach)
* **Language:** TypeScript
* **State Management:** Redux Toolkit (for global state like Theme)
* **Custom UI:** Custom components for dynamic elements like the **Experience Bar** and the **Technology Proficiency Map**.

## 🤖 The Role of Generative AI (Gemini)

This project was intentionally built using **Gemini** as the primary coding assistant and architectural guide, rather than a direct VS Code Copilot integration.

### Goals of the Experiment:
* **Learning Focus:** The decision to avoid direct IDE copilot usage forced manual typing and implementation of code generated by Gemini. This was critical for **internalizing React/Next.js concepts** like Server Components, Client Components, Context, and Hooks.
* **Architectural Guidance:** Gemini was tasked with solving complex structural problems, such as:
    * Implementing a **Client/Server boundary** for interactive components (`'use client'`).
    * Structuring the project to handle **multiple landing pages** with static prop passing.
    * Debugging subtle framework issues (e.g., the **hydration mismatch** error).
* **Development Acceleration:** Gemini provided boilerplate for complex UI elements (like the `TechnologyMapGrid` or `ExperienceBar`), significantly reducing the time spent on initial component scaffolding and utility class setup.
